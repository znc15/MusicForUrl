# 开始使用

## 打开播放器

进入 [music.nyasakura.com](https://music.nyasakura.com/)，从侧边栏“账号管理”登录网易云或 QQ 音乐。每个平台保留一个当前账号；重新登录可切换账号。

1. 在“链接生成”粘贴歌单链接或 ID，也可从“我的音乐”选中歌单。
2. 生成后点击“预览”，在播放队列中选歌，使用原生播放、暂停、进度与音量控制。
3. 通过音质下拉框选择档位；旁边显示平台实际返回的格式与码率。
4. 若需要外部播放器，复制签名 M3U8。链接默认有效 24 小时，退出账号立即撤销。

## 媒体预览

本站生成的歌单使用逐首音频预览，封面与播放状态同时展示。外部 HTTPS 视频、M3U8 或本地文件仍可在“视频预览”打开。本地文件只在浏览器播放，不上传。

外部 HLS 要求来源允许跨域。Cloudflare 轻量 M3U8 是音频清单，不包含视频画面；VRChat 还受世界允许域名、播放器后端与账号设置限制。详见 [音质与限制](./quality)。

## 主题与账号偏好

导航底部可切换亮色 / 深色。背景、文字、面板统一进行短过渡，尊重系统“减少动态效果”。本机账号名称、备注、常用平台和音质选择保存在浏览器；不修改音乐平台资料。
